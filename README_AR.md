# حزمة المساعد الذكي متعدد المهارات

## الوصف

هذه الحزمة تقدم إعدادات جاهزة لمساعد ذكي عام يحاكي **أسلوب العمل والمهارات العامة** لمساعد احترافي متعدد الاستخدامات. صُممت لتكون مستقلة عن منصة بعينها؛ لذلك يمكن وضع ملف التعليمات في خانة التعليمات النظامية أو التعليمات المخصصة في أي منصة تدعم ذلك.

> هذه الحزمة ليست استنساخًا للنظام الداخلي أو للهوية الخاصة بأي خدمة. إنها مواصفة مستقلة لمساعد مشابه في السلوك والقدرات العامة.

## محتويات الحزمة

| الملف | الوظيفة |
|---|---|
| `system_instructions.md` | التعليمات الرئيسية التي تُستخدم كتعليمات نظام أو تعليمات مخصصة. |
| `assistant_profile.json` | ملف تعريف منظم للهوية والقدرات وقواعد الإخراج والسلامة. |
| `README_AR.md` | هذا الدليل المختصر للاستخدام والتخصيص. |

## طريقة الاستخدام

انسخ محتوى `system_instructions.md` كاملًا والصقه في خانة **System Prompt** أو **Custom Instructions** في المنصة التي تستخدمها. إذا كانت المنصة تدعم ملفات تعريف JSON، استخدم `assistant_profile.json` بوصفه مرجعًا إضافيًا أو حوّله إلى الإعدادات المكافئة في تلك المنصة.

بعد الإضافة، يمكن استخدام المساعد في البحث، الكتابة، التلخيص، تحليل البيانات، البرمجة، إنشاء المستندات، بناء المواقع والتطبيقات، إعداد العروض، تصميم المحتوى البصري، معالجة الوسائط، والأتمتة. تتوقف بعض القدرات العملية على الأدوات والصلاحيات التي توفرها المنصة المضيفة.

## إعدادات افتراضية مقترحة

| الإعداد | القيمة المقترحة |
|---|---|
| اللغة | لغة المستخدم الأولى، والعربية الفصحى افتراضيًا |
| النبرة | مهنية، واضحة، مباشرة، ومبادرة |
| مستوى التفصيل | متوسط، مع زيادة التفصيل في الأعمال التقنية أو المعقدة |
| طرح الأسئلة | الحد الأدنى فقط عندما يكون السؤال ضروريًا فعلًا |
| التحقق | مراجعة النتيجة قبل التسليم |
| الملفات | تسليم الملف النهائي مباشرة عند إنشائه |

## قواعد التخصيص

يمكن إضافة اسم للمساعد، أو تخصص مهني، أو جمهور مستهدف، أو نبرة مختلفة، دون حذف قواعد الدقة والسلامة والخصوصية. لتخصيصه، أضف فقرة قصيرة في نهاية ملف التعليمات تحت عنوان **تخصيص المستخدم**.

مثال:

```text
## تخصيص المستخدم
اسم المساعد: المساعد التنفيذي.
الجمهور: فريق شركة ناشئة.
الأولوية: تحويل الأفكار إلى خطط ومخرجات قابلة للتنفيذ.
النبرة: مهنية ومختصرة.
```

## حدود التشغيل

قدرات المساعد الفعلية تعتمد على المنصة التي تستضيف هذه التعليمات. فإذا لم توفر المنصة تصفحًا أو تنفيذ كود أو إنشاء ملفات أو أدوات خارجية، فسيقتصر المساعد على ما تسمح به تلك المنصة. يجب عدم وضع مفاتيح سرية أو بيانات حساسة داخل ملفات التعليمات.

## اختبار سريع

بعد تثبيت التعليمات، استخدم طلبًا تجريبيًا مثل:

```text
حلّل هذا الهدف، أنشئ خطة تنفيذ عملية، نفّذ ما يمكنك مباشرة، ثم سلّمني النتيجة النهائية مع توضيح موجز لما تم إنجازه.
```

النتيجة المتوقعة هي أن يحدد المساعد الهدف، يتخذ افتراضات معقولة عند نقص التفاصيل، ينفذ العمل، يراجع الناتج، ثم يسلّم مخرجات واضحة بدل الاكتفاء باقتراحات عامة.
