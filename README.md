> مساحة عمل عربية تجمع المحادثة الذكية، الأدوات، الملفات، والمحفوظات في تجربة عملية متجاوبة.

## الموقع الحي

يمكنك فتح النسخة المنشورة مباشرة من [smartassist-8btpufdw.manus.space](https://smartassist-8btpufdw.manus.space). توجد مساحة العمل الداخلية على المسار `/workspace`، بينما يعرض المسار الرئيسي الموقع التعريفي للحزمة.

## ما الذي يقدمه المشروع؟

يقدم نواة محادثات متعددة الجلسات، وسياقًا مرتبطًا بالملفات، وأدوات لمسارات الكتابة والبرمجة وتحليل المحتوى، ومكتبة للنتائج الحديثة، وإدخالًا صوتيًا يتحول إلى نص. تعتمد العمليات المحمية على مصادقة المستخدم، وتُحفظ الملفات عبر التخزين الآمن مع بيانات وصفية مرتبطة بالجلسة.

| المسار | الغرض |
|---|---|
| `/` | الموقع التعريفي العربي ومحتوى الحزمة |
| `/workspace` | مساحة المحادثات الداخلية |
| `/workspace/tools` | مسارات الأدوات |
| `/workspace/library` | المكتبة والنتائج الحديثة |

## التشغيل محليًا

```bash
pnpm install --frozen-lockfile
pnpm dev
```

للفحص والاختبارات والبناء:

```bash
pnpm check
pnpm test
pnpm build
```

## التشغيل داخل GitHub

يمكن فتح **Code → Codespaces → Create codespace on main** لتثبيت المشروع وتشغيله داخل بيئة GitHub. كما يمكن تشغيل Workflow **تشغيل التطبيق مؤقتًا** من تبويب Actions لفحص الأنواع والاختبارات وتشغيل الخادم وفحص الصحة. التفاصيل موجودة في [GITHUB_RUN.md](GITHUB_RUN.md).

## النشر الخارجي

المشروع الحالي تطبيق كامل يجمع واجهة React وخادم Express وطبقة tRPC وقاعدة بيانات؛ لذلك لا يكفي نشر ملفات الواجهة الثابتة وحدها على Vercel. يمكن ربط مستودع GitHub بخدمة خارجية بعد تجهيز محول للخادم وقاعدة البيانات وإدارة الأسرار، بينما تبقى النسخة المنشورة الحالية متاحة عبر رابط الموقع الحي أعلاه. لا تُضع مفاتيح سرية داخل المستودع.

## التحقق المستمر

يعمل GitHub Actions عند الدفع وطلبات السحب، وينفذ فحص الأنواع والاختبارات وبناء الإنتاج. راجع [سجل التنفيذ](https://github.com/abdelatizarzori3-sys/smart-assistant-app/actions) لمعرفة الحالة الحالية.
